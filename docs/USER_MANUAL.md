# 知华 SRM 用户操作说明

适用版本：企业交付版。界面分为采购管理端和供应商门户，账号可见范围由后端角色和数据域决定。

## 1. 登录与账号

使用管理员分配的账号登录。连续失败达到阈值后账号临时锁定；不要多人共用账号。首次登录后及时修改密码。系统管理员在“系统管理”创建采购、质量、财务、审计或供应商账号，并为供应商账号绑定对应企业。

## 2. 供应商准入

1. 采购在“供应商管理”创建限时邀请。
2. 供应商使用邀请完成企业资料、联系人、供货范围和银行信息登记。
3. 供应商上传证照，按产能、质量、交付、合规、服务五部分填写准入问卷并提交；字段未填写完整时系统不允许提交。
4. 采购进行初审与终审；退回时填写原因。
5. 终审通过后供应商转为合作状态。后续资料或状态变更均保留变更原因和审计记录。

采购可根据实际情况将供应商转为整改、暂停、淘汰或黑名单。银行账号在普通列表中只显示掩码。

## 3. 寻源询报价

采购新建 RFQ/RFP，填写物料、数量、需求日期、截止时间、预算并选择受邀供应商。发布后，仅受邀供应商可在门户查看。供应商可提交报价版本和澄清问题；采购在比价页面查看各供应商最新版本，完成基础综合评审后选择报价并填写定标原因。结果通过站内消息通知参与方。

## 4. 合同管理

采购维护合同编号、供应商、金额、币种、有效期、附件和版本原因。状态按“草稿 → 待审批 → 已审批 → 生效”流转。需要调整时从最新已完成审批版本创建新版本，新版本生效后原生效版本转为“已替代”。详情页展示订单执行金额、履约率和全部版本。系统每天生成 30 天到期提醒，过期生效合同自动转为失效。

## 5. 采购订单

采购可通过页面/API 创建订单，或使用 xlsx 模板批量导入。导入会先校验全部表头和数据行；存在任一错误时整批不写入，并返回行号和原因。供应商可整单确认，也可逐行反馈确认数量、交期和备注。采购可变更行数量、单价和交期；系统保存变更前快照、重新发起确认，并按稳定订单行来源增减配额占用。

## 6. 配额管理

1. 新建配额方案，选择采购组织、工厂、物料、有效期和类型。
2. 比例配额的供应商分配合计必须为 100；数量配额合计必须等于计划总数量。
3. 草稿校验通过后启用；同一范围和重叠有效期不能同时存在多个生效版本。
4. 供应商确认订单行时，系统按订单号和行号幂等扣减已用配额。
5. 无方案、未分配、余额不足或超配时，订单标记异常并向采购生成待办。
6. 在配额列表导出当前分配、已用、剩余和预警状态。

## 7. 交付协同

供应商基于自己的订单创建 ASN，选择订单行和发货数量。采购设置预约时间，供应商登记承运商和运单号，采购按 ASN 行登记实收数量和差异原因。系统同步更新订单收货比例与交付状态。

## 8. 质量协同

采购创建 NCR/CAR 并设置严重度和截止日期。供应商开始分析后填写根因、临时措施、永久措施和证据附件。采购可退回整改或进入验证；验证通过后填写结论并关闭。详情页可查看该质量问题的完整操作历史，采购可导出本组织质量问题 Excel。

## 9. 对账、发票、绩效与风险

采购按供应商和期间生成基础对账，系统冻结每个订单行的订单数量、实收数量、价格和结算金额快照。供应商确认或提出异议；确认后可登记发票，同一对账单发票号不可重复，累计金额不能超过结算金额。采购按质量、交付、成本和服务评分；低绩效、证照临期/过期、订单逾期和质量整改逾期会生成来源可追溯的规则风险，后续分配整改、验证并关闭。

## 10. 消息、附件和审计

“消息与待办”集中展示询价、订单、异常等事项，可标记已读或完成。自动规则按业务来源幂等生成待办，不会在每天扫描时重复创建。附件仅允许白名单格式并校验文件签名和大小，下载按组织和供应商归属校验。审计角色可按操作人、模块和时间范围查询操作对象、修改前后内容、IP 和时间。

## 常见问题

- 看不到业务数据：确认账号角色、组织以及供应商绑定关系。
- 导入失败：根据错误明细修复整份文件后重新导入；系统不会部分导入。
- 订单提示配额不足：检查物料、采购组织、工厂、有效期和供应商分配是否匹配。
- 文件无法下载：确认文件归属当前组织或当前供应商，且存储卷未丢失。
- 登录被锁定：等待锁定时间结束或联系管理员核验后处理。
