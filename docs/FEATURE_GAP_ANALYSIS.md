# 知华 SRM 企业级升级功能差距分析

> 基线：`知华SRM生产级系统_功能清单及报价表.xlsx`（2026-09-30）  
> 范围原则：只实现清单中的 30 项标准功能。明确排除 MRP、计划同步、计划发布，以及相关导航、接口、表和验收内容。

## 现状结论

当前代码是演示原型，不满足生产交付条件。后端仅包含供应商、询价、报价、采购订单、质量问题和用户 6 类基础实体；前端主要依赖静态模拟数据；启动时会写入演示账号与演示数据。现有权限只到角色级，供应商隔离仅覆盖少数订单接口，缺少审计、配额、合同、ASN、对账、文件权限、导入事务和完整状态机。

状态说明：

- **完整**：功能、权限、状态、持久化和测试均可按清单验收。
- **部分**：存在可复用代码，但缺少清单中的关键能力。
- **未实现**：没有可用业务实现。
- **不可生产**：存在代码，但包含静态数据、演示账号、越权风险或缺少事务/审计等生产问题。

## 实施顺序与依赖

1. **安全底座**：组织、用户权限、供应商数据隔离、账号锁定、审计、软删除、乐观锁。
2. **配额管理**：配额方案与分配、版本生效、订单占用、余额预警、查询与导出。
3. **供应商生命周期**：邀请、资料、证照、准入、审批、重复识别、黑名单和变更留痕。
4. **寻源与合同**：询价行、定向邀请、报价版本、澄清、比价、定标、合同版本与提醒。
5. **订单与交付**：事务型导入、订单行确认、变更版本、异常、ASN、收货差异。
6. **质量、结算与绩效**：NCR/8D、整改闭环、对账、发票、评分和风险整改。
7. **PC 响应式前端**：采购端、供应商门户、统一状态与异常交互。
8. **生产交付**：迁移脚本、环境变量、监控、备份、接口/数据库/部署/用户文档及验收测试。

## 复用、修复和新增边界

- **复用**：Spring Boot、JPA、Security、JWT、Vue 3、现有品牌样式、基础供应商/询价/订单/质量实体命名。
- **修复**：认证配置、演示初始化、供应商隔离、分页、异常返回、硬编码仪表盘、订单/报价状态流转。
- **新增**：组织权限、审计、消息待办、供应商生命周期、合同、配额、ASN、对账发票、文件、导入导出、生产监控及完整文档。
