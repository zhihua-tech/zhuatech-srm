## 核心流程覆盖

- 邀请并注册两个供应商，提交问卷，完成两级准入审批。
- 创建定向 RFQ，两个供应商分别报价，采购比价并定标。
- 创建合同并完成提交、审批、生效、新版本和历史查询。
- 创建数量配额，验证多供应商合计并启用版本。
- 创建多行订单，验证另一供应商无法访问；逐行与整单确认，订单行数量/单价/交期变更后配额按稳定来源幂等同步。
- 订单数量超过分配量时生成超配预警并标记订单异常。
- 创建 ASN、预约、发运、收货并记录短少差异。
- 创建 NCR，供应商提交整改，采购验证关闭，并验证对象级历史和 Excel 导出。
- 生成包含订单行快照的基础对账，供应商确认并登记发票。
- 验证证照临期自动提醒/风险、绩效结果及按操作人/模块筛选审计日志。

详细测试代码位于 `backend/src/test/java/cn/zhuatech/srm/EnterpriseSrmWorkflowIntegrationTests.java`。
