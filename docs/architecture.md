# 企业交付架构

上海如静知华信息科技有限公司 · [知华科技官网](https://www.zhuatech.cn/)

## 运行边界

```text
采购人员浏览器 ─┐
                ├─ HTTPS 反向代理 ─ Vue 3 单页应用 ─ /api ─ Spring Security ─ 领域服务 ─ MySQL 8.4
供应商浏览器 ───┘                                      │              │
                                                        │              ├─ 受控附件目录
                                                        │              └─ Flyway 迁移
                                                        └─ JWT + 接口权限 + 组织/供应商数据域
```

采购管理端和供应商门户共用构建产物，登录后按角色进入不同路由。前端菜单只负责呈现；后端控制器通过方法级权限校验操作权限，服务层再按 `organization_code` 与 `supplier_id` 限制数据范围。

## 后端结构

| 层 | 责任 | 约束 |
| --- | --- | --- |
| Controller | HTTP、参数校验、权限声明 | 不直接访问 Repository |
| Service | 状态流转、业务校验、数据域、审计 | 关键写操作使用事务 |
| Repository | 分页及带组织/供应商条件的查询 | 禁止为供应商入口提供无范围查询 |
| Model | 领域状态、乐观锁、软删除 | 关键实体继承 `BaseEntity` |
| Security | JWT、账号锁定、服务端权限矩阵 | 除登录、受邀注册和健康检查外默认认证 |
| Migration | Flyway 版本化数据库变更 | 已发布迁移禁止修改 |

## 数据隔离

- 采购侧查询固定携带当前用户 `organization_code`。
- 供应商账号必须关联一个供应商，门户查询固定携带该 `supplier_id`。
- 订单、合同、询价邀请、报价、ASN、质量问题、对账、绩效、风险和附件均在服务层执行范围校验。
- 附件下载同时校验组织和供应商归属，存储路径由服务端生成，不接受客户端路径。
- 审计记录单独事务写入，包含组织、操作人、模块、动作、对象、修改前后内容、客户端 IP 和时间。

## 状态与一致性

- 供应商：准入中、待审批、合作、整改、暂停、淘汰、黑名单。
- 寻源：草稿、开放报价、评审、待定标审批、已定标、关闭、取消。
- 合同：草稿、待审批、已审批、生效、到期、终止。
- 订单：待确认、部分确认、已确认、发运、部分收货、完成、取消。
- 配额：草稿、生效、失效、取消；同范围重叠生效版本受业务校验约束。
- ASN、质量问题、对账和风险均有显式状态流转。
- `@Version` 提供基础乐观并发控制；导入在单事务内校验全部行后写入，任一错误整体回滚。

## 扩展建议

客户研发团队可从对应 Service 扩展审批节点、消息通道、对象存储或外部业务接口。新增表结构使用新的 Flyway 版本；新增供应商入口必须复用 `CurrentUserService.requireSupplier()` 做数据域约束；新增关键写操作必须调用 `AuditService`。
