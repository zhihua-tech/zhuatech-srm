# 已知限制与实施边界

以下内容不影响本次核心业务闭环，但在特定企业环境上线前需要按客户基础设施完成配置或扩展：

- 邮件、短信和企业微信通知尚未内置，当前使用站内消息与待办；可在消息创建点接入客户通知平台。
- 附件默认保存到持久化文件卷，集群部署建议替换为带服务端加密和生命周期策略的对象存储。
- 银行账号普通接口已掩码，数据库静态加密需结合客户 KMS、密钥轮换和合规要求实施。
- HTTPS 由反向代理或云负载均衡终止，应用容器不直接管理证书。
- 内置角色提供默认权限矩阵，组织管理员可以在页面替换各角色权限；复杂岗位、字段级权限或客户 IAM 仍需按客户制度对接。
- 基础综合评审采用可维护的业务字段；复杂评分模板、电子签章、税务验真和外部主数据校验需对接客户现有平台。
- 容灾目标、备份保留、日志平台、告警阈值和容量基线需要在客户生产基础设施中落地并演练。
